# AI 个人电脑存储能力·对外测试案例矩阵

版本：对外展示版 1.0

## 文档定位

本表面向客户、合作伙伴和非测试专业读者，用于说明 AI 个人电脑存储能力的验证范围与用户价值。表中的技术内容已转换为用户场景和可感知结果，不展开内部测试框架、执行命令、协议参数或实现名称。

内部详细测试项可按本表的案例编号进行归并和追溯；对外沟通时以本表的场景、指标和结论为准。

## 设计原则

- 以用户真实使用流程为主线，覆盖首次使用、日常交互、内容创作、可靠性和长期稳定性。
- 用“等待时间、完成率、空间余量、恢复时间”等可理解的指标表达结果。
- 技术细节只保留对产品结论有帮助的内容，不展示内部框架、脚本、命令和具体实现名称。
- 结论采用“通过、条件通过、未通过、未执行”四种状态，并对异常给出简短说明。

## 对外结果呈现建议

对外报告可按以下五类汇总，不必展示内部执行细节：

1. **日常交互体验**：首次启动、重复启动、切换、长对话和多任务响应。
2. **本地内容处理**：文档问答、知识库、图像或视频生成、本地处理任务。
3. **容量与空间管理**：模型、文档、临时文件和输出同时存在时的空间余量。
4. **长期稳定性**：高占用、高温和日常循环使用中的性能变化。
5. **可靠性与恢复**：保存、睡眠、唤醒、重启和运行中断后的恢复结果。

每类建议只保留“结论、关键指标、异常说明、适用边界”四项内容。具体阈值可根据产品定位和目标用户另行约定。
